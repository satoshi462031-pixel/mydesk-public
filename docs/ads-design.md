# アプリ内広告の設計

作成日: 2026-10-15  
状態: 設計のみ。**ユーザーが1000人を超えたら検討を始める**（2026-10-15 本人決定）。
SDK を入れるビルドも、ATT を聞くかどうかも、そのときに決める。
今のコードは `AdBanner`（`ADS_ENABLED = false`）の空の枠だけで、何も描画しない。

## 1. 方針

- 広告は「Pro に入る理由」を作る役割が大きい。利用者が少ないうちの広告収入は小さく、
  収益の柱はアフィリエイト（購入リンク）と Pro。
- 画面の流れを止める広告（全画面・下に固定するバナー）は使わない。
- 自分のもの（マイデスク）の中には挟まず、末尾に置く。X・Instagram もプロフィールや自分の投稿一覧には出していない。
- ガジェット詳細には置かない。購入リンクがこの画面の広告の役割を持っていて、AdMob を置くと食い合う。

## 2. 他アプリから取り入れる型・取り入れない型

| 型 | 例 | 扱い |
|---|---|---|
| インフィードのネイティブ広告（中身と同じ形に「広告」を付けて混ぜる） | X・Instagram・WEAR・Pinterest・メルカリ | 採る（みんなのデスク） |
| 一覧の末尾の、行と同じ形のカード＋「広告を非表示にする」 | WordHolic | 採る（マイデスク一覧・マイガジェット） |
| 下に固定するバナー | WordHolic ほか | 採らない。タブバーと隣り合って誤タップを生み、写真を見せる縦幅を常に削る |
| 区切りの全画面広告 | mikan・Duolingo（レッスンの後） | 採らない。公開の直後に挟むと投稿する人の体験を壊す |
| リワード広告 | mikan・Duolingo | v2 で検討（下の 5.） |
| 商品リンク | WEAR（ZOZOTOWN へ） | 既存の購入リンクがこれにあたる（`affiliate` の方針に従う） |

## 3. v1 の配置

### A. みんなのデスク（`DeskFeedScreen`）：グリッドの1マス

- `DeskGridTile` の compact と同じ大きさ。写真の位置に広告の画像（MediaView）、タイトルの位置に見出し、
  日付の行（「3日前」「新着」が出る行）に「広告・広告主名」。新着・更新と同じ場所なので、広告だと読み取れる。
- 頻度：6枚目のあとに1つ、以降は10枚ごと。
- 対象は通常のフィードだけ。検索結果・ユーザータブ・ブランドや機材の段には入れない。
- 実装の要点：デスクを2件ずつ組む前（`pushDesks`）の並びに広告の印を差し込む。読み込めた広告だけを差し込み、
  見えている位置より上にはあとから入れない（一覧がずれる）。失敗した枠は詰める。
- このタイルには「広告を非表示にする」を付けない。隣のタイルと高さが揃わなくなり、広告の中にアプリのボタンを
  重ねる形は AdMob で誤クリック扱いになりやすい。

### B. マイデスク一覧（`PlanListScreen`）・マイガジェット（`GadgetLibraryScreen`）の末尾：横長のカード

- 左に画像、右に見出し・広告主・CTA。角丸・地・文字色は `colors` と `UI_METRICS` から引き、ダークモードで浮かせない。
- カードの外のすぐ下に「広告を非表示にする」を置き、Paywall へ飛ばす。
- `AdBanner` の中身を差し替える。呼び出し側（2画面のフッター）は変えない。
- デスク・ガジェットが0件のときは出さない（空の画面に広告だけが残る）。

### 共通

- Pro と、課金状態の確認中は出さない（`AdBanner` の今の判定のまま）。
- AdMob の管理画面で、デリケートなカテゴリ（出会い・ギャンブルなど）を止める。ゲーム全体は止めない（埋まる率が落ちる）。
- 有効にするときは、`src/constants/plans.ts` に「広告非表示」の行を同じフラグで足す（実在しない特典を載せないため、今は載せていない）。
- 計測：「広告を非表示にする」の押下と、そこからの Pro 加入を PostHog で取る。表示回数と収益は AdMob 側で見る。

## 4. 始めるときに決めること

- **SDK を入れるビルド。** `react-native-google-mobile-ads` はネイティブのモジュールで、OTA では足せない。
  v16 と Expo SDK 54 の組み合わせで config plugin が読めないという報告がある
  （invertase/react-native-google-mobile-ads#820）。入れる時点の Expo SDK との相性を先に確かめる。
- **ATT を聞くか。** 聞かなければパーソナライズされない広告だけになり、単価は下がる。聞くなら初回起動ではなく、
  オンボーディングのあと。`NSUserTrackingUsageDescription` はビルド時に入るので、SDK と同じビルドで決める。
- App Store のプライバシーラベルの更新、AdMob アカウントの開設と支払い情報（広告収入は所得になる。扶養の線に注意）。
- 「ユーザー1000人」の数え方（登録数か、週のアクティブか）。`docs/metrics/README.md` の定義に合わせる。

## 5. v2 で検討

- 公開デスク（`PublicDeskScreen`）の機材リストの末尾。最後まで見た人がいる位置で、写真と機材の間には挟まない。
- 統計・保存一覧・閲覧履歴の末尾。
- リワード広告。AI コーチは無料プランでは使えないため、「動画で1回試せる」形になり、Pro の価値と食い合う。出すかどうかから考える。
- 自社広告：広告が埋まらない枠に Pro の案内を出す。
