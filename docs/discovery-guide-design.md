# 「みんなのデスク」の案内設計

作成日: 2026-10-02  
状態: 実装済み。初回の案内と画面別ヘルプを追加。現行の画面・操作を確認して作成。

## 1. 到達点

初めて使う人が、公開デスクを1件開き、機材と配線図の見方を理解できることを目標にする。保存・拍手・フォローは、本人が必要になったときに使えるよう説明する。

案内は次の2つで構成する。

- **初回の短い案内**: 一覧とデスク詳細に、各1回だけ表示する。
- **この画面の見方**: 表示の意味と操作方法を、利用者がいつでも開いて調べられるようにする。

デスク作成の6段階のガイドとは独立して開始・終了する。デスク作成の途中で「みんなのデスク」を開いても、作成ガイドの進捗を変更しない。

## 2. 初回の流れと文言

| 場面 | 表示場所 | 見出し・本文 | 閉じる条件 |
|---|---|---|---|
| 「みんなのデスク」を初めて開く | 一覧の先頭。検索・対象タブより下、最初のセクションより上 | **気になるデスクを開いてみる** / みんなが公開したデスクを、写真・機材・配線図で見られます。写真かデスク名をタップしてください。 | デスク詳細を開く、または「案内を終了」 |
| 公開デスクを初めて開く | 「機材」タブの一覧先頭 | **機材とつなぎ方を見る** / ここには、このデスクで使われている機材が並びます。上の「配線」で、つなぎ方も見られます。 | 「配線」「履歴・分析」へ切り替える、または「案内を終了」 |

本文末の操作を実際に行うと案内を畳む。「次へ」を押して説明だけを読み進める操作は設けない。

カードには「表示の意味を詳しく」というリンクも置く。押すと、その画面のヘルプシートを開く。カードは通常のスクロール内容として高さを確保し、写真・機材・操作ボタンの上には重ねない。

配線図を開いた後は、そのまま図を見られる。完了ダイアログや保存の要求は出さない。

英語文言:

| ID | Title | Body |
|---|---|---|
| `explore-open-desk` | Open a desk you like | Explore desks people have shared, including photos, gear, and wiring maps. Tap a photo or desk name. |
| `explore-desk-tabs` | Explore the gear and wiring | These are the gadgets used on this desk. Open Wiring above to see how they connect. |

「案内を終了」は `End guide`、「表示の意味を詳しく」は `Learn what’s shown` とする。

## 3. 「この画面の見方」の入口と構成

一覧・公開デスク詳細のヘッダー右上に「?」を1つ置く。読み上げ名は「この画面の見方」。押すと `BottomSheetModal` を開く。閉じると、検索条件・スクロール位置・表示タブを保って元の画面へ戻る。

シートは見出しを押して開く形式にし、最初は現在の表示に対応する項目だけ開く。

- 一覧: 「探し方」「カードの表示」「機材・ユーザーの一覧」「更新のお知らせ」
- 詳細: 「写真・機材・配線・履歴」「保存と拍手」「投稿者・共有・自分のデスク作り」

説明する印は、実際のアイコンやバッジを文の横に表示する。利用者にアイコンの名前を覚えさせない。

設定 → ヘルプ・使い方には「みんなのデスクの見方」を追加し、同じ内容を読めるようにする。既存の作成ガイドは「デスクを作るガイド」と表示して区別する。ヘルプを開くだけでは画面移動やデスク作成を開始しない。

## 4. 一覧で説明する表示と操作

以下をヘルプの本文に使用する。すべてを初回カードへ詰め込まない。

| 表示 | 利用者向けの説明 | 操作・配置上の扱い |
|---|---|---|
| 写真・デスク名 | 公開されたデスクです。タップすると写真や詳しい構成を見られます。 | 写真・デスク名を開く既存操作を使う。 |
| デスク名の下の用途アイコン | ゲーム、仕事など、このデスクの用途を表しています。 | 一覧のアイコンはカードの一部。個別タップで用途名が出るとは案内しない。実際の用途アイコンと名前をヘルプに併記する。 |
| 投稿者名・丸い写真 | このデスクを公開した人です。 | 一覧カード内の名前のタップも現在はデスクを開く。投稿者のプロフィールは詳細画面から開く、と説明する。 |
| カードの日付 | この公開デスクの更新日です。 | 台数や購入日と誤認させないため、カードの日付には「更新」を添える案。 |
| 「新着」 | 公開から7日以内で、まだ開いていないデスクです。 | バッジが実際に出る条件と揃える。 |
| 「更新」 | 前に開いたときから内容が更新されています。 | 一覧の「最近更新された順」とは別の、本人の閲覧履歴をもとにした印。 |
| 拍手の印と数字 | 気に入ったデスクに拍手できます。数字は届いた拍手の累計です。 | 数字を閲覧数・保存数・人数とは説明しない。拍手済みは押すと取り消せる。ログインが必要。 |
| 検索欄 | デスク名、投稿者、機材名などで探せます。 | 入力例は「モニター」「仕事」などの短い語にする。 |
| 「すべて / デスク / ユーザー」 | 表示する対象を切り替えます。「すべて」にはデスク・機材・ユーザーが並びます。 | 並び順の切り替えとは説明しない。現在の画面には機材専用タブはない。 |
| 絞り込み・色の付いた点 | 用途や機材のジャンルなどで絞れます。点が付いていると絞り込み中です。 | 条件チップを外す操作、フィルタ内のリセットを説明する。 |
| 最近のデスク | 最近更新された公開デスクです。 | 人気順・おすすめ順位とは説明しない。 |
| よく使われている機材・「○デスク」 | 公開デスクで使われている機材です。数字はその機材を使っている公開デスクの数です。 | 機材名をタップすると、その機材を使っているデスクへ絞り込まれる。 |
| 公開中のユーザー・「○デスク」 | デスクを公開している人と、その人の公開デスク数です。 | ユーザーの行をタップするとプロフィールを開く。 |
| 「検索結果はここまで」 | ここより下は、検索結果に関連するジャンルやおすすめのデスクです。 | 現在の境界の説明文をその場に残す。 |
| ベル・ベルやタブの点 | 保存したデスクやフォロー中の人の更新、自分のデスクへの拍手を確認できます。点は新しいお知らせがある印です。 | ベルを開いて確認する。アプリ全体のエラーや未処理の作業とは説明しない。 |

## 5. デスク詳細で説明する表示と操作

| 表示 | 利用者向けの説明 | 補足 |
|---|---|---|
| 写真 | 投稿者が登録したデスク写真です。タップして大きく見られます。 | 写真がない場合は写真操作の項目を表示しない。 |
| 用途アイコン | このデスクの用途です。タップすると用途名が表示されます。 | 詳細の `DeskPurposeIcons` はタップ対応。一覧の用途アイコンとは操作が異なる。 |
| 機材 | このデスクで使われている機材です。機材をタップすると詳しい情報を見られます。 | 登録されていない情報まで見られるとは約束しない。 |
| 配線 | 登録された機材・接続情報をもとにした配線図です。拡大や移動をして確認できます。 | 色の意味は図の凡例で確認する。「全体」で図を画面に収める。登録情報をもとにした図であることを伝える。 |
| 履歴・分析 | 登録された機材の変化や、構成の集計を見られます。 | データがない場合は空状態の説明を優先する。 |
| 保存 | あとで見返したいデスクを残せます。マイページの「保存」から開けます。 | ログインが必要。写真の端末ダウンロードや自分のデスクへのコピーとは異なる操作。 |
| 拍手 | 投稿者に「いいね」の気持ちを届けます。拍手済みを押すと取り消せます。 | ログインが必要。「もう一度拍手」は前の拍手後に内容が更新された場合に表示される。 |
| 投稿者・フォロー | 投稿者を開くと、その人の公開デスクを見られます。フォローすると更新を追えます。 | フォローをガイドの完了条件にしない。 |
| 共有 | このデスクのリンクを共有できます。 | 共有は本人が選んだ場合だけ通常の共有操作へ進める。 |
| このデスクを参考に作る | ジャンルの組み合わせや配置を参考にして、自分の機材でデスクを作れます。 | 既存の機材一覧末尾の説明を使う。保存とは別操作であることが分かるようにする。 |

URL限定のデスク、自分のデスク、写真や機材のないデスクでは、実際に使える操作だけを説明する。公開一覧に出さないURL限定デスクを「みんなのデスクで探せる」と案内しない。

## 6. その場の補足

初回の自動カードを増やす代わりに、操作先の画面へ短い補足を置く。

- 絞り込みシート: 見出しの下に「用途や機材のジャンルで、公開デスクを絞れます」。
- ベルの更新画面: 一覧の先頭に「保存したデスク・フォロー中の人の更新と、あなたのデスクへの拍手が届きます」。
- 保存が実際に成功した初回: 既存の完了表示があれば「保存しました。マイページの『保存』で見返せます」に統合する。新しいポップアップを重ねない。失敗時やログインを促しただけの時には成功案内を出さない。

## 7. 表示条件・終了・再表示

- 初回カードは、画面が手前にあり、対応するデータを読み込めて、カードが実際に画面内に入ったときに既表示を記録する。マウントや取得成功だけでは既表示にしない。
- 一覧の初回カードは、通常の「すべて」表示でデスクが1件以上あるときに出す。検索や絞り込みを始めたらその訪問中は畳む。検索条件付きで直接来た人には先に検索結果を見せる。
- 詳細の初回カードは、他人の公開デスクの「機材」一覧を正常に表示できたときに出す。共有リンクや保存一覧から来ても、このカードだけで意味が通じる文言にする。
- 自分の公開デスク、データなし、エラー、読み込み中では、自動カードを出さない。ヘルプの入口は使える。
- 自動カードは、1画面につき最大1枚。同じカードは通常の再訪問・再起動で出し直さない。
- 「案内を終了」は探索用の自動案内全体を終了する。後から詳細へ進んでも別の自動カードは出さない。説明は「?」や設定からいつでも読める。
- 作成ガイドが表示中、キーボード入力中、写真ビューアや別シートを開いている間は、自動案内を重ねない。未表示のまま見送ったカードは既表示にしない。
- 既表示は端末共通で保持する。ログインをきっかけに案内を出し直さない。文章の修正だけでは既表示をリセットしない。
- ヘルプは閉じるボタンと通常の戻る操作で閉じられる。背景の画面を操作させる初回カードには暗幕を付けない。

## 8. 実装の範囲

| 場所 | 予定する変更 |
|---|---|
| `src/screens/DeskFeedScreen.tsx` | 初回カード、ヘルプの入口、絞り込みの補足。既存の更新プレビューと同じ `ListHeaderComponent` 内で縦に配置する。 |
| `src/screens/PublicDeskScreen.tsx` | 「機材」タブ先頭の初回カードと、状況に合う詳細ヘルプ。配線のキャンバスには案内を重ねない。 |
| `src/components/molecules/DeskGridTile.tsx` | 発見用一覧の日付に「更新」を添える。共有部品なので変更条件は `discoveryOrder` に限定する。 |
| `src/screens/DeskUpdatesScreen.tsx` | ベルの対象を説明する短い文。 |
| `src/screens/SettingsScreen.tsx` | 作成ガイドの表示名を具体化し、探索ヘルプの入口を追加する。 |
| 新規の案内カード・ヘルプシート | 日英の文言を共有し、現在の画面・データ・利用可能な操作に合わせて表示する。既存のシートとテーマ定数を使う。 |
| 新規の探索ガイド状態 | 固定IDの既表示集合と `dismissed` を保存する。作成ガイドのステップ配列・完了キーは流用しない。 |

状態の候補は `@explore_guide_v1: { seen: ['explore-open-desk', 'explore-desk-tabs'], dismissed: boolean }`。読み込みが間に合わない間は自動カードを表示しない。破損時は既表示扱いにして通常閲覧と手動ヘルプを使えるようにする。

ブランドの入口は現在無効なので、ブランドの探し方は表示対象に含めない。案内表示のための新しいデータ取得は行わず、画面が取得済みのデータから対象を判定する。

## 9. 実装後に確認すること

1. 初回の一覧から写真・デスク名を押せて、詳細の機材・配線へ移動できる。
2. 自動カードを閉じても、戻る・検索・絞り込み・別タブへの移動ができる。
3. カードとヘルプが、写真・検索候補・キーボード・下部ボタンに重ならない。小さい画面、文字拡大、日本語・英語で確認する。
4. 一覧の用途アイコンと詳細の用途アイコンで、説明した操作が実際の動作と一致する。
5. 空・通信失敗・共有リンク・URL限定・自分のデスクでも、できない操作を要求しない。
6. 「案内を終了」、再起動、ログイン後に自動案内が復活しない。設定と「?」から説明を開ける。
7. 作成ガイドの途中で探索へ移っても、戻ったときの作成ガイドの進捗が保たれる。

成果は「公開デスクを開けたか」「機材の詳細や配線まで見られたか」で判断する。案内を閉じた割合や拍手・保存の件数だけで成否を決めない。

計測を追加する場合は、既存の分析同意に従い、表示・終了・ヘルプ閲覧の固定IDだけを使う。ガイドの表示数は画面内での実表示から数え、検索語・デスク名・商品名を新たに送らない。
