## 5. 申し立てが来たとき

1. 放置しない。期限内に返答する（App Store の申し立ては、Apple から開発者へ連絡が来る）。

3. 相手が名前の変更を求め続ける場合は、弁理士に相談してから、変更するか争うかを決める。
   その場合に直す箇所：`app.json` の `name`、ストア掲載文、LP、worker、`mydesk.page`（共有URL・App Links）、公式アカウント @MyDesk。
