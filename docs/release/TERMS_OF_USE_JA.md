# MyDesk 利用規約

制定日：2026年8月24日  
最終改定日：2026年9月29日

本利用規約（以下「本規約」といいます。）は、MyDesk運営者（以下「運営者」といいます。）が提供するアプリケーション「MyDesk」、関連ウェブサイト、公開ページ、AIデスクコーチその他これらに付随するサービス（以下、総称して「本サービス」といいます。）の利用条件を定めるものです。

利用者は、本規約の内容を確認し、同意したうえで本サービスを利用するものとします。利用者が本サービスを利用した場合、またはアカウント登録時に本規約への同意操作を行った場合、本規約に同意したものとみなします。

## 第1条（適用）

1. 本規約は、本サービスの提供および利用に関する運営者と利用者との間の一切の関係に適用されます。
2. 運営者が本サービス上で掲載するガイド、注意事項、プラン説明、コミュニティルールその他の個別規定は、本規約の一部を構成します。
3. 本規約と個別規定の内容が異なる場合、個別規定に別段の定めがない限り、個別規定が優先して適用されます。

## 第2条（本サービスの内容）

1. 本サービスは、主として次の機能を提供します。
   1. デスク、ガジェット、価格、購入日、ポート、配線、導入・撤去履歴その他の情報の記録および管理
   2. 登録情報に基づく配線図、集計、履歴表示その他の補助機能
   3. デスク情報および写真の公開、共有、閲覧、保存
   4. AIによるデスク環境、機材構成または配線に関する参考提案
   5. アカウントバックアップおよび復元
   6. 商品情報および外部販売サイトへのリンクの表示
   7. その他、運営者が随時追加する機能
2. 一部の情報は端末内に保存されます。公開、共有、自動バックアップ、アカウント同期、AI機能その他通信を伴う機能を利用した場合、必要な情報が運営者または外部委託先のサーバーへ送信されます。
3. 本サービスは、専門家による設計、電気工事、安全検査、医療、法律、投資その他の専門的助言を提供するものではありません。

## 第8条（AIデスクコーチ）

1. AIデスクコーチは、利用者が入力した文章、写真または画像ならびに送信画面で有効にしたデスクの機材・仕様、ポート、接続関係、必要ケーブル、配線上の警告および任意の価格・日付に基づき、自動生成された参考情報を表示します。
2. AIの回答には、誤り、不完全な情報、古い情報、実在しない製品名、不適切な表現または利用者の意図と異なる内容が含まれる場合があります。
3. 利用者は、AIの回答をそのまま信用せず、製品仕様、互換性、定格電力、発熱、耐荷重、配線方法、保証条件、価格、在庫その他重要事項を、メーカー、販売事業者、有資格者その他信頼できる情報源で確認するものとします。
4. 電源、電気工事、火災、感電、機器の破損、転倒、身体への影響その他安全に関わる判断は、必要に応じて有資格者または専門家へ相談してください。
5. 利用者は、AIへの入力に、パスワード、APIキー、本人確認書類、金融情報、健康情報、第三者の個人情報、未公開情報その他の機密情報を含めないものとします。
6. AI回答を違法行為、危険行為、権利侵害、欺罔、差別、嫌がらせその他不適切な目的に利用してはなりません。
