# 配線図の回避・交差・分岐ルール

現行実装の回避方法と、図の読み方をまとめる。配線の経路は接続関係を読みやすくするための表現であり、実物のケーブルの上下関係・長さ・取り回しを示すものではない。

## 何を、どう避けるか

| 対象・状況 | よけ方 | 図の読み方 |
| --- | --- | --- |
| 接続先以外の機器が途中にある | 機器の外側へ縦横の線で迂回する。通常は機器の周囲に余白を取る | 機器の内部を通る経路は通常の候補に採用しない |
| 直線で届く | 直線を優先し、必要な場合だけL字や複数の曲がりを使う | 障害物がなければ、回避のためだけの遠回りを増やさない |
| 上下・左右の両方に通り道がある | 通過可能性、重なり、出入りする辺、交差・曲がり・長さを比較する | 常に右へよける、常に上へ回るという固定ルールはない |
| 別のケーブルと直角に交わる | 交差を許容し、背景色の縁取りで下に描く線を途切れさせる。交差点だけは上の線に沿って背景色を短く敷き、切れ目を縁取りより広げる | 切れ目は交差であり、接続ではない。交差ごとに半円の橋は描かない。下の線の口（端）に近い交差では、口まで切らないよう切れ目を狭める |
| 別のケーブルと長く重なる・近接して並ぶ | 通路内の別レーンへ横にずらし、必要なら引き直す | 別の線が1本に見える重なりの解消を、交差数の削減より優先する場合がある |
| 同じ機器から出る線が絡む | 接続点の並びや出入りする辺を見直してから、経路を引き直す | 出口の直後に線を無理に折り曲げて解消しない |
| 登録された分岐ケーブル | 共通の機器側で同じ接続点を使い、共通経路から分かれる位置に丸印を付ける | 分岐と宣言したケーブルだけが対象。同じ色・同じ端子・偶然の接触だけでは分岐にしない |

## 回避経路の選び方

1. 接続点を決め、機器の辺から外向きに出入りする経路を探す。障害物のない直線・L字を先に試し、必要なら上下左右のグリッド探索で迂回する。
   同じ向きの辺どうし（上辺と上辺など）のコの字は、両端の機器のすぐ外を通る候補と、間にある機器すべての外側を回る候補の両方を比べる。
2. 通常の候補では機器の貫通を除外する。相手を通り過ぎて裏側から刺さるような回り込みも避ける。
3. 候補の読みやすさは、同じ機器を共有する線との重なり、反対側の辺への回り込み、他線との重なりの順に比較する。その後に `交差数 × 140 + 口の近くの交差数 × 200 + 曲がり数 × 120 + 経路長` を比較する。口の近くの交差とは、別の機器の接続点から外向きに `MAP_STUB_OUT + MAP_CLEAR = 22` 以内で横切ること、または自分の接続点から22以内で引き終えた線を横切ること。切れ目が口のすぐ外に来ると、横切った線がその機器へつながって見えるため、普通の交差より重く数える（自分の両端の機器の口どうしは対象外）。
4. 同点に近い場合は、端子近くの曲がり、機器の角への寄り過ぎ、交差数・曲がり数・長さ、座標から作るキーの順で決める。左右・上下の方角そのものを優先しない。
5. 配置後に交差と並走を補修する。全体を外周へ大回りさせたり、交差を1個減らすために曲がりを無制限に増やしたりしない。
6. 最後に途中の迂回を短絡して曲がりを減らす。このとき、余白を取れている線を余白なし（機器の縁すれすれ）の経路へ置き換えない。もともと狭い通路を通っている線だけは、狭いまま短くしてよい。
   直線・L字に加え、既存の通路や途中の2点の中央を使う2回曲がりも比較し、階段状の迂回をまとめる。交差合計だけでなく、口元の交差と、同じ機器を共有する線の絡み・同じ2本の複数交差がある相手の数も増やさない。

ここでの候補比較は、探索した候補の中での判断。探索量に上限があるため、すべての経路を比較した最短経路の保証ではない。

## どちらの線を動かすか

交差補修では、同じ機器を端点として共有するペアは交差0回、それ以外のペアは1回以下を目標にする。これは補修の目標であり、最終結果の保証ではない。

- 共通の機器上で同じ辺から出る線は、まず接続点の入れ替えを試す。
- 次に、片方の線が出入りする辺を変更して解消できるか試す。
- それでも解消しなければ、片方が相手の経路をよける候補を試し、不適切ならもう片方を試す。対象の順は処理中の配線順に従い、「横線が必ずよける」とは決めない。
- 辺を替える補修は、曲がりの増加を2回、長さの増加を140図座標までに抑え、折り返し・他線との交差・近接並走が増える候補を除く。通常の経路引き直しでは曲がりを増やさず、別の場所の重なりや交差超過も悪化させない。
- 両端の辺を替える直線・L字の補修では、同じ曲がり数なら、1本だけ使う辺の接続点が中央に近い候補を距離より優先する。複数本のファンアウトや分岐元の固定点は寄せず、中央が他の接続点に近すぎる場合も強制しない。
- レーン分割では、近接並走が減る場合に交差の増加を許容することがある。分割を戻して再び1本に見える状態にはしない。
- 同じ辺から出る足の深さを段違いにするのは、足の先の辺平行区間が重なる（12未満まで近づく）ときだけ。辺の両端から逆向きに出る線は同じ深さのままにし、隣の機器の際へ押し付けない。

## 描画の上下と回避方向は別

交差の上下は描画順で決まる。通常は無線・支持関係などの補助線、電源線、信号線の順に描き、同じ層では長い線を下に置く。同じ層・同じ長さなら元の順を維持する。種類を強調したときは、その種類を前面に出す。

これは見やすさのための重ね方であり、上に描く線が実物でも上を通るという意味ではない。また、上に描く線・下に描く線のどちらを迂回させるかを決める規則でもない。

分岐の丸印は、同じ `branchGroupId` に属し、共通機器が一意で、同じ端点から共通経路をたどる枝が分かれる位置だけに付く。分かれた後の再交差には付けない。履歴再生では枝が描き終わってから表示し、一部撤去後は残った枝に合わせて表示を更新する。

## 余白の基準

値はズーム前の図座標。画面上のピクセルや実物の距離とは異なる。

| 項目 | 現行値・扱い |
| --- | --- |
| 機器を避ける通常の余白 | `MAP_CLEAR = 9` |
| 接続点から外向きに出る足 | `MAP_STUB_OUT = 13` |
| 色付き線／背景色の縁取りの幅 | `5.5 / 11` |
| 交差点の切れ目（下の線に沿った長さ） | `16`（`WIRE_CROSSING_CUT_WIDTH`）。縁取りだけの `11` は全体表示（約0.4倍）で片側1pt ほどになり、交差が分岐の十字に見えた。並走レーンの隣の線を欠かない上限は約19 |
| 近接並走を見分ける間隔 | 中心線間12を目安に判定し、レーン分割時は12.5を使う |
| 別ポートの接続点間隔 | 通常は14を基準とする。辺の容量や回避条件によって確保できない場合がある |

線幅だけを太くすると、機器との余白や隣のレーンを塞ぐ。寸法を変更する場合は、線幅・余白・レーン間隔を一緒に確認する。

## 通常の回避で経路が見つからない場合

現行実装は接続自体を図から消さないため、段階的な救済を行う。

1. 通常の候補がなければ、余白を2に縮めたグリッドと別の接続点で再探索する。接続点の固定・中央寄せ、電源幹線を跨がない条件、別配線との接続点共有を避ける条件も緩める。
2. それでも見つからなければ、機器の外側の座標を使ったコの字の逃げ道を試す。ここまでは、機器を貫通しない候補だけを採用する。
3. 逃げ道の候補も見つからなければ、貫通が少なく、曲がりと長さを抑えた線を最後の手段として描く。機器の重ね置きなどでは、機器を通る線が残りうる。

この最後の状態を「回避成功」とは扱わない。探索上限もあるため、見つからなかったことだけで通路が存在しないとは断定できない。余白や交差回数を常に保証するには、この救済表示と配置の見直しを別途設計する必要がある。

## 確認例

- AとBの間に機器Cがある → Cの外側を縦横に回る。通常経路はCを貫通しない。
- 別ケーブルが十字に交わる → 切れ目で区別し、丸印は付けない。
- 別ケーブルが横に長く重なる → 別レーンへずらす。交差を減らすだけの大回りは避ける。
- 同じ機器から出る2本が絡む → 接続点と出入りする辺を先に見直す。
- 2in1ケーブルが分かれる → 共通経路から分かれる点に丸印を付ける。
- 機器の重ね置きなどで経路探索が失敗する → 上記の救済処理に進み、通常の余白・非貫通を保証しない。
