# 機能・画面操作のデバッグ（2026-10-03）

MyDesk のローカル Web 版で操作と保存結果を確認した。技術構成の点検は対象外。

## 修正

1. マイデスクと公開デスクの詳細・編集画面に残っていた更新日ラベルを削除し、従来選んでいた更新日の日付のみを表示。
2. Web で日付欄を押すと空のネイティブピッカーが開く問題を修正。Web は日付の直接入力にし、日本語・英語の書式、全角数字、最小・最大日、クリアを扱う。iOS / Android のピッカーは継続。
3. AI相談履歴を開き直して再生成・再試行すると写真が送られない問題を修正。写真付きの質問は保存画像を復元する。復元できない場合は写真なしで送信せずエラー表示。復元・利用枠確認の途中で会話を切り替えたり停止した場合は旧質問を送信しない。
4. ひとことの行数測定用の非表示テキストが Web の読み上げ対象に重複する問題を修正。
